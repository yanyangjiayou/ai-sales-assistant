# AI 销售助理工作台 · Sales AI Workbench

> 一个由想法快速落地的 B 端销售赋能产品原型，也是我的 **vibecoding（AI 辅助编程）** 实战作品。

**一句话定位**：在不改造企业现有 CRM 的前提下，用「AI 战术参谋 + 人必确认」的方式，把销售跟进里的零散信息，变成可赢单的洞察、策略与话术。

---

## 这是什么

AI 销售助理是一个面向 B2B 销售人员的「单页工作台 + 客户档案作战室」原型。它不走传统 CRM「重录入」的老路，而是让销售用语音 / 粘贴快速沉淀跟进，由 AI 负责解析、洞察、出策略与备话术，但**所有关键动作都由人显式触发与确认**。

## 为什么做（问题 & 机会）

- **CRM 普遍失活**：销售不愿手动录入（麻烦，且与赢单无直接关联），手机端沉重打不开。
- **销售最缺的是「下一步说什么」**：有数据没洞察，有客户没打法。
- **我的切入**：把 AI 放在「参谋」位置——出洞察、给证据、备话术，但**点击权与对外动作归人**。

## 我的角色（AIPM / AI 产品经理）

作为该项目的 AI 产品经理，我端到端负责：

- **需求与场景**：销售痛点访谈、主管协作链路梳理、竞品（CRM）对比；
- **信息架构与交互设计**：三栏工作台（事务 / AI 帮助 / 数据）、客户档案作战室；
- **AI 能力边界设计**：制定「黄金法则」——AI 只建议、人必确认、人负责对外；
- **验收与迭代**：编写 T1–T30 验收清单，用 Superpowers 工作流驱动 V1.4 → V2.2 快速收敛。

## 核心设计亮点

1. **黄金法则 / Human-in-the-loop**：档案写入必经销售勾选确认；向主管求助做成「一键复制、人来发送」，不越过人际边界，也不需任何 IM 集成。
2. **五维意向评分（D1–D5）**：评分是「已确权数据」的派生指标，不回写、可展开看逐条证据；D5 还展示销售主观备注——透明、防黑箱。
3. **沟通预演（综合实战检验）**：AI 扮演客户**随机抽题**（每个痛点保底考 1 次），5 轮攻防后输出「痛点×轮次矩阵」报告，并诚实记录是否开了小抄。
4. **知识库缺口不硬编**：内部命中 <40% 时，AI 不编造方案，改为「复制信息发给主管 + 补录知识库」，把误用风险变成资产积累。
5. **轻录入激励闭环**：语音 / 粘贴即解析、草稿 24h 恢复、AI 待办带 🤖 徽章且可忽略降敏——主动而不骚扰。

## 我是怎么 vibecoding 出来的

- **工具链**：以 Superpowers（AI Agent 工作流）的 `writing-plans → executing-plans` 流程驱动；AI 负责方案草案与代码实现，我负责判定、验收与边界拍板。
- **迭代速度**：从 V1.4 到 V2.2（原型 V1 → V10），4 处关键收敛（统一综合预演 / 直觉备注 / 复制转发 / D2 口径）在单日完成，并经代码级断言验证（T25–T30）。
- **人机分工**：这正是 AIPM 该有的工作方式——**AI 扩产，人掌舵**。

## 成功度量（怎么算做成了）

- **过程指标**：单条跟进结构化耗时↓、AI 待办采纳率、知识库命中率↑
- **结果指标**：销售赢单率、跟进完整率、主管求助闭环时长
- **模型校准**：意向评分权重按本司赢单样本每周回归校准；D2 以「信息获取质量」计，不以客户主动与否论英雄。
