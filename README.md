# AI 销售助理工作台 · Sales AI Workbench

> 一个把销售零散信息变成「可赢单洞察 · 针对性策略 · 可发话术」的 B 端销售赋能原型。

**一句话定位**：在不改造企业现有 CRM 的前提下，用「AI 战术参谋 + 人必确认（Human-in-the-loop）」的方式，把**录音、文字、CRM、知识库多端信息打通**，自动分析客户痛点、生成应对策略和可直接发给客户的话术。

---

## 📌 这是什么

AI 销售助理是一个面向 B2B 销售人员的**单页工作台 + 客户档案作战室**原型。它不走传统 CRM「重录入」的老路，而是让你用**语音 / 粘贴**快速沉淀跟进，由 AI 负责解析、洞察、出策略、备话术，但**所有关键动作都由人显式触发与确认**。

- 🟢 零依赖、纯静态单文件，**双击即可离线运行**
- 🟢 演示态使用 mock 数据，不涉及真实客户隐私
- 🟢 架构上打通多端信息源，可直接作为产品落地的交互基线

---

## 🔗 多端信息打通（核心架构）

本项目最大的特点不是「又一个 CRM」，而是把销售日常散落在各处的信息**汇聚到同一份客户档案**，由 AI 统一加工：

```
  🎤 录音 / 语音录入        📄 微信·企微·邮件文字粘贴       🗂 现有 CRM 系统信息
        │                          │                            │
        └──────────────┬───────────┴────────────────────────────┘
                       ▼
               ┌──────────────────────┐
               │   统一汇聚 · 客户档案   │  ← 作战室（痛点/需求/阻力/决策链/生命周期）
               └──────────┬───────────┘
                          ▼
               📚 知识库（弹药库）检索  ── Hybrid Retrieval / RAG 思路
                          ▼
               🤖 AI 自动解析 → 结构化「痛点 · 阻力 · 需求」
                          ▼
               🎯 针对性策略（洞察 → 证据链 → 策略卡）
                          ▼
               💬 可直接发给客户的参考话术（一键复制）
                          ▼
               🥊 沟通预演（AI 扮演客户随机抽题）
```

> 设计原则：**多端采集、单点汇聚、AI 加工、人做决策**。CRM 只作为信息源之一，不要求企业替换现有系统。

## ✨ 功能亮点

1. **🩺 客户痛点自动分析** —— 从录音 / 文字 / CRM 多源信息中，由 AI 自动解析出结构化「需求 / 痛点 / 阻力」，标注来源与更新时间，可逐条勾选确认入档。
2. **🎯 针对性策略输出** —— 不堆通用建议。先给心理洞察（引用客户原话），再配知识库证据链，最后**按每个痛点生成对应策略卡**，痛点与打法一一对应。
3. **💬 一键生成可发客户的话术** —— 把策略翻译成**一段可直接复制发微信 / 邮件的消息正文**：价值前置、给具体时间选项（二选一）、主动上门，绝不是「您看看哪条合适」这类把球踢回给客户的傻话术。
4. **🥊 沟通预演（综合实战检验）** —— AI 扮演客户**随机抽题**（每个痛点保底考 1 次），多轮攻防后输出「痛点 × 轮次矩阵」报告，并诚实记录是否开了小抄。
5. **📚 知识库 = 弹药库** —— AI 检索的第一证据源。内部命中度 < 40% 时**不编造方案**，改为「复制信息发给主管 + 补录知识库」，把误用风险变成资产积累。
6. **📊 五维意向评分（可解释）** —— 评分是「已确权数据」的派生指标，可展开看逐条证据与提升建议，透明、防黑箱。
7. **🛡 黄金法则 / Human-in-the-loop** —— AI 只建议、不点击不生效；档案写入必经销售确认；向主管求助做成「一键复制、人来发送」，不越过人际边界，也不需任何 IM 集成。
8. **⚡ 轻录入激励闭环** —— 语音 / 粘贴即解析、草稿 24h 恢复、AI 待办带徽章且可忽略降敏 —— 主动而不骚扰。

## 📋 主要功能清单

**工作台（指挥中心）**
- 三栏布局：左栏事务（今日待办 / 风险预警）、中栏 AI 助理（锦囊 / 发现 / 双 CTA）、右栏数据（目标 / 排名 / 战报）
- AI 自动提取待办，带「🤖 AI 建议」徽章，整卡可点进入客户档案

**跟进录入与 AI 解析（链路起点）**
- 三类来源：🎤 语音录入 / 📄 录音转文字粘贴 / ⌨️ 手动输入
- 居中大模态解析，结果分「需求 / 痛点 / 阻力 / 情绪」四组，**勾选 + 程度 + 备注**后三选一确认
- 多点温和提醒录入，绝不代录

**客户档案作战室（六块结构）**
- ① 客户基础信息 + 决策链 DMU　② BANT 三件套（需求 / 痛点 / 阻力）　③ AI 策略区　④ 配套资料（知识库切片）　⑤ 全生命周期时间轴　⑥ AI 助理横幅提醒

**AI 策略生成（痛点 → 策略 → 话术）**
- 手动触发「🔄 生成 AI 策略」→ 心理洞察 1/2/3 → 突破解法 + 知识库证据链 → 策略卡 1/2/3 → 每张卡生成参考话术
- 知识库匹配 < 40% 时降级为人工升级指引，不硬编

**参考话术生成**
- 针对每条策略生成可直接发给客户的消息正文（价值前置 + 具体时间二选一 + 主动上门）
- 绿色「📋 一键复制发给客户」按钮，复制即所得

**沟通预演**
- 模块级唯一入口「▶ 开始综合预演」
- 抽题引擎：每个痛点保底 1 次、难度递进、不给考点提示
- 报告：总分 + 四维能力 + 痛点 × 轮次矩阵 + 逐轮点评 + 小抄次数

**知识库（弹药库）**
- 文档式布局，成单案例完整字段
- 外部证据回流机制：主管确认后的求助内容沉淀为正式条目

**五维意向评分**
- D1–D5 加权，点击展开看五维依据、趋势、单条提升建议
- 缺证据时给出明确补录提示

**成单自动检测**
- 模拟 CRM 定时检测成单 → 自动总结成交案例入知识库 + 回写数据 + 战报
