# AI 销售助理 · 面试讲解脚本

> 用途：AIPM 面试中介绍这个 vibecoding 作品。建议先讲 2 分钟版建立全貌，再用 5 分钟版展开记忆点（沟通预演随机抽题）。

## 一、2 分钟电梯演讲

1. **问题**：传统 CRM 销售不愿用（录入重、与赢单脱节）；销售最缺的是「下一步说什么」。
2. **解法**：做一个 AI 销售助理——语音 / 粘贴快速沉淀跟进，AI 出洞察、证据、策略、话术，但**关键动作人必确认、对外动作人来做**。
3. **我的角色**：AI 产品经理，负责需求、交互、AI 边界设计、验收。
4. **最亮的点**：① 黄金法则（HITL）防 AI 幻觉越权；② 沟通预演让 AI 扮客户随机抽题考你，出「痛点×轮次矩阵」报告。
5. **vibecoding**：用 AI Agent 工作流驱动，V1 → V10 单日收敛 4 处关键设计，代码级验收。

## 二、5 分钟展开（按六条演练串）

- **演练 1 看全貌**：点客户 → 展开五维评分依据（注意 D2 来源标注、D5 备注原文）→ 看时间戳溯源。
- **演练 2 录入闭环**：贴一段跟进 → 解析 → 四分组勾选（取消一项低置信）→ 选程度 + 填备注 → 确认 → 看时间轴 / 留痕 / 评分联动。
- **演练 3 仅保存**：验证字段不动、时间轴 +1、蓝点亮、D5 留档。
- **演练 4 压轴 · 综合预演**：生成策略 → 构造 <40% 看「复制发主管」→ 点唯一「开始综合预演」→ 5 轮客户在不同痛点间跳跃 → 报告精确指出你失手的痛点、小抄用了几次。
- **演练 5 / 6**：成单检测案例沉淀；手机端单列 + 悬浮球。

## 三、尖锐问题预案

**Q：AI 幻觉怎么办？**
A：三条防线——① 所有写入必经人确认（黄金法则）；② 低置信 (<75%) 默认不勾选，逼人决策；③ 知识库 <40% 不编造，走主管升级。AI 是参谋不是执行官。

**Q：隐私 / 合规？**
A：严格按《个人信息保护法》《数据安全法》：录音仅用于结构化分析、加密存储、知情同意、默认 90 天清除、可撤回。

**Q：为什么不做自动写入 / 自动发消息？**
A：责任归属（档案是公司资产）、信任（亲自确认才敢用）、噪声防火墙（防幻觉放大）、渠道尊重（对外动作本就在人的人际网络里）。设计铁律：AI 不点击不生效，出系统的动作归人。

**Q：意向评分怎么定权重？**
A：从过往赢单经验回归得出初始值，上线后按本司样本每周校准；D2 改以「信息获取质量」计，体现强控场能力；评分是派生指标、不回写、可溯源防黑箱。

**Q：你怎么用 AI 做的（vibecoding 细节）？**
A：以 Superpowers 的 writing-plans → executing-plans 流程：我先写需求与验收（plan），AI 出实现草案，我审边界与一致性，再验收（T25–T30 代码级断言）。人定方向与标准，AI 扩产。

## 四、一句话收尾
